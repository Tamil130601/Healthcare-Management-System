Healthcare Management System - A Salesforce application for managing patients, doctors, appointments, medical requests, and healthcare activities. The system uses Salesforce automation and development features to streamline healthcare processes and improve operational efficiency.

Features:

- Patient Management
- Doctor Management
- Appointment Management
- Medical Request Management
- Automated Email Notifications
- Automated Task Creation using Flows
- Patient Search using LWC
- REST API Integration
- Reports & Dashboards

Technologies Used:

- Salesforce
- Apex
- SOQL
- Lightning Web Components (LWC)
- Salesforce Flows
- Validation Rules
- REST API
- Postman
- Reports & Dashboards

Custom Objects:

- Patient
- Doctor
- Appointment
- Medical Request

Key Highlights:

- Automated appointment processes using Flows
- Automated email notifications to patients
- Automated task creation for doctors
- Patient search using LWC
- Healthcare data integration using REST API
- Interactive reports and dashboards
